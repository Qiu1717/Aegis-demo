## 1. 产品目标

**一句话**：把现有的「纯聊天 Flask Web 助手」改造成「下载安装包 → 双击安装 → 填自己的 API Key → 直接可用的桌面端编码 Agent」——让 Aegis 能读本地代码、改文件、跑命令、多步自主迭代完成任务，同时保留现有对话能力作为交互底座。

三条主线：

1. **能力升级**：从"只回答"升级为"能动手"——读/检索/写/改/跑命令 + 多步规划自主迭代 + 人在环路确认。
2. **桌面端分发**：产出 Windows 安装包（macOS 条件允许时兼顾），不要求用户本机安装 Python / Node / Ollama。
3. **模型与密钥自治**：GUI 配置服务商与模型，密钥本地加密存储，零内置密钥，失败有明确中文提示。

### 2.3 现有实现中的三个**必须在本次改造中修正**的问题

| 问题 | 现状 | 风险 | 要求 |
|---|---|---|---|
| `main.py` 用 `host=0.0.0.0, debug=True` | 监听所有网卡 + 开调试器 | 桌面端等于把本地 Agent（含文件读写、命令执行能力）暴露到局域网，**高危** | 桌面端必须改为 `127.0.0.1` + `debug=False` |
| `CORS(app)` 全开 | 任意来源可跨域调用本地接口 | 恶意网页可驱动本地 Agent 执行命令（DNS rebinding / CSRF） | 收紧为仅本机来源 + 本地 token 鉴权 |
| 密钥明文落在 `config.json` | `load_config()` 直接读 JSON，无加密 | 用户密钥可被其他程序/同步盘读取 | 改为加密存储（见 6.5），`config.json` 只存非敏感项 |

## 3. 用户故事

### 主线一：编码 Agent 能力（US-01 ~ US-04）

- **US-01** 作为**开发者**，我想让 Aegis 直接读取我本地项目里的文件并回答，以便它给出的建议是基于我真实代码而不是凭空猜测。
- **US-02** 作为**开发者**，我想用自然语言描述"给 `main.py` 加上请求日志"就让它自动定位改哪里并改好，以便省去我手工搜索和编辑的时间。
- **US-03** 作为**开发者**，我想让 Aegis 自己拆解任务、连续执行多步（读 → 改 → 跑测试 → 修 → 再跑），以便一次交付可运行的改动，而不是来回问答十几轮。
- **US-04** 作为**开发者**，我想在它修改文件或执行危险命令前弹出确认，看到具体 diff 或命令原文再决定，以便我对代码库的最终状态有完全掌控。
- **US-05** 作为**开发者**，我想让它帮我跑 `pytest` / `pip install` / `git status` 并把输出直接展示给我，以便不用在编辑器和终端之间来回切换。
- **US-06** 作为**项目维护者**，我想限定 Aegis 只能在我指定的工作区目录内操作，以便它不会误删或误改我电脑上的其他文件。

### 主线二：桌面端分发（US-07 ~ US-09）

- **US-07** 作为**不想折腾环境的用户**，我想下载一个安装包、双击安装、双击图标就能用，以便不用在本机装 Python、配虚拟环境、装 Ollama 或 Node 工具链。
- **US-08** 作为**Windows 用户**，我想安装后在开始菜单和桌面有图标、卸载走系统"添加/删除程序"，以便它像一个正常软件而不是一个脚本。
- **US-09** 作为**macOS 用户**（条件允许时），我也想拿到 `.dmg` 安装包并正常通过 Gatekeeper 打开，以便和 Windows 用户获得一致体验。
- **US-10** 作为**用户**，我想我的会话历史、配置和日志都放在我自己的用户目录下，以便卸载重装或升级时不丢数据、也不需要管理员权限写入。

### 主线三：模型与密钥配置（US-11 ~ US-14）

- **US-11** 作为**不想为大模型付费的用户**，我想在界面里直接看到每个服务商的免费额度说明和申请链接，并能一键选到免费的 GLM-4-Flash，以便我只用免费额度就能跑起来。
- **US-12** 作为**注重安全的用户**，我想在 GUI 里填我自己的 API Key 并被加密保存在本机，以便密钥既不出现在安装包里也不会被明文看到。
- **US-13** 作为**用户**，我想第一次打开应用时有向导一步步引导我完成配置，且没配好之前明确告诉我"现在不能用"，以便我不会被一个沉默失败的应用卡住。
- **US-14** 作为**用户**，我想在调用失败时看到"API Key 无效 / 余额不足 / 限流 / 网络不可达"这样的具体中文提示和下一步该做什么，以便我能自己修好而不是对着一串异常发呆。
- **US-15** 作为**用户**，我想随时切换服务商或模型，并能点"测试连接"立刻确认是否可用，以便某个服务挂掉时我能马上换一个继续用。

## 4. 需求池

优先级定义：**P0 = 本次必须实现的最小闭环**（缺一项则产品不成立）；P1 = 应当有，可二期；P2 = 锦上添花。
编号规则：`AEG-A*` 编码 Agent / `AEG-D*` 桌面端 / `AEG-K*` 模型与密钥。

### 4.1 P0 —— 最小闭环（Must Have）

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| **AEG-A01** | **文件读取与目录列举工具**：提供 `read_file`（含行号、可选行区间）、`list_dir`（含忽略规则：`.git`/`node_modules`/`__pycache__`/`.venv`） | ① Agent 能在一次任务内读取工作区任意文本文件并在回答中引用其中原文；② 单文件超过 N 行时自动分段并在 UI 提示"已截断"；③ 读取工作区外路径直接拒绝并给出明确提示 |
| **AEG-A02** | **本地代码库检索**：提供 `grep_search`（正则/关键词 + 文件后缀过滤 + 结果条数上限）；先做关键词，**不做向量** | ① 关键词检索返回 `文件:行号:内容`；② 单次调用结果条数上限可配置（默认 50）；③ 检索范围限定在工作区内 |
| **AEG-A03** | **文件创建与修改工具**：`write_file`（新建/整文件覆盖）、`replace_in_file`（精确字符串唯一匹配替换） | ① 新建文件后磁盘上确实存在且内容一致；② `replace_in_file` 在匹配数 ≠ 1 时**必须报错而非猜测**；③ 所有写入前先落 `.aegis_backup/` 备份 |
| **AEG-A04** | **终端命令执行工具**：`run_command`，在**工作区根目录**下执行，带超时、输出截断、可中断 | ① 能正确拿到 stdout/stderr/exit_code 并展示；② 超时（默认 120s，可配）后自动终止并提示；③ 用户可点"中断"立即停止；④ 命令始终以工作区为 cwd，禁用 `cd` 逃逸 |

| **AEG-A06** | **多步规划与自主迭代**：Planner 产出步骤清单 → Executor 逐步执行 → 观察结果 → 迭代，带最大步数上限与终止条件 | ① 一次"读 → 改 → 跑测试 → 修"任务可自动跑完，全程无需用户逐步点击；② 达到最大步数（默认 20，可配）时优雅停止并汇报已完成部分；③ 每步结果实时推送到 UI |
| **AEG-A07** | **人在环路审批**：写文件、修改文件、执行非只读命令前弹确认；危险命令无条件二次确认 | ① 未确认不落盘/不执行；② 提供"本次任务内始终允许"与"仅此一次"两种粒度；③ 危险命令（删除、格式化、覆盖、`rm -rf`、`del /f`、`git push --force`、注册表、系统目录写入等）**始终**弹窗且不允许被"始终允许"豁免 |
| **AEG-A09** | **Agent 事件流扩展**：在现有 SSE 上新增 `step` / `tool_call` / `tool_result` / `approval_request` / `diff` / `terminal` / `done` 事件类型 | ① 前端能按事件类型分区域渲染（任务步骤/文件变更/终端）；② 与现有 `delta`/`provider`/`notice`/`error` 事件向后兼容，旧前端不报错 |

| **AEG-D02** | **本地会话鉴权**：启动生成随机 token，所有 `/api/*` 请求校验；token 仅通过启动参数/临时文件传给窗口 | ① 无 token 或 token 错误的请求返回 401；② 浏览器直接打开页面无法调用写/执行类接口 |
| **AEG-D03** | **PyInstaller 打包与构建脚本**：产出可执行的桌面程序（含 Flask 后端 + 静态资源 + templates + 默认配置） | ① 在一台无 Python 环境的干净 Windows 机器上双击可直接运行；② 构建脚本一键执行，产物路径固定；③ `templates/`、`static/`、`config/` 均正确打包进产物 |

| **AEG-D05** | **桌面启动器**：启动本地服务 → 打开内嵌窗口（pywebview 或系统默认浏览器）→ 关闭窗口时优雅停止服务 | ① 双击图标 10 秒内看到界面；② 关闭窗口后后台 Python 进程**确实退出**（无残留）；③ 端口被占用时自动换端口并提示 |
| **AEG-D06** | **用户数据目录与日志落盘**：数据库、加密密钥库、配置、日志写入用户目录（Windows `%APPDATA%\Aegis\`），不写程序安装目录 | ① 普通用户权限安装即可正常运行（不需要管理员写权限）；② 升级/重装后会话历史与配置仍在；③ 日志文件按大小滚动，不无限增长 |

## 6. 非功能需求

### 6.1 安全（最高优先级）

| 项 | 要求 |
|---|---|
| 网络暴露面 | 后端仅监听 `127.0.0.1`；`debug=False`；CORS 仅允许本机来源 |
| 本地鉴权 | 每启动生成随机 token，所有 `/api/*` 校验；token 不落明文配置文件 |
| 路径沙箱 | 所有读写/命令路径归一化后必须落在已授权工作区内；拒绝 `..` 逃逸与符号链接跨越；系统目录、用户主目录非工作区部分**默认禁止** |
| 命令沙箱 | 命令在工作区根目录执行；维护**危险命令黑名单**（删除/格式化/`rm -rf`/`del /f`/`shutdown`/注册表/`curl \| sh`/`git push --force`/包管理全局卸载等），命中即无条件二次确认；提供只读命令白名单（如 `ls/dir/git status/pytest -q`）可选免审批 |
| 写操作审批 | 新建文件、覆盖写入、精确替换**默认需审批**（可开"自动批准"开关，默认关闭） |
| 备份与回滚 | 每次写入前落 `.aegis_backup/` 备份；P1 支持任务级一键回滚 |
| 超时与中断 | 命令默认超时 120s（可配）；UI 可中断；输出截断上限（默认 64KB） |
| 步骤上限 | 单任务最大步数默认 20（可配），防止死循环烧 token |
| 错误信息 | 沿用现有约定：详细异常只写日志，前端只给通用中文文案 + 建议动作 |
| 密钥 | 全 UI 掩码；不写日志；不进 `config.json` 明文；不进安装包 |

### 6.2 性能

| 场景 | 指标 |
|---|---|
| 冷启动到界面可交互 | ≤ 10s（Windows 主流配置） |
| SSE 首字延迟 | ≤ 2s（网络正常情况下，沿用现有流式链路） |
| `list_dir`（≤5k 文件） | ≤ 1s；`grep_search` ≤ 3s（P1 加缓存后更快） |
| 单文件读取 | ≤ 500ms；超 2000 行自动分段并提示截断 |
| 命令输出渲染 | 实时流式，UI 不阻塞 |
| 内存占用 | 常驻 ≤ 500MB（不含被 Agent 启动的子进程） |
| 长会话 | 轨迹按 token 预算裁剪，不出现 OOM 或请求超窗 |

### 6.3 跨平台

| 平台 | 级别 | 要求 |
|---|---|---|
| Windows 10/11 x64 | **P0 优先** | 完整安装包 + 快捷方式 + 卸载入口；DPAPI 加密；中文路径、中文输出（UTF-8）无乱码 |
| macOS 12+（Intel + Apple Silicon） | **P1 兼顾** | `.app` / `.dmg`；Keychain 加密；签名方案见 Q4/Q5 |
| Linux | 不在本期范围 | 仅保持代码结构可移植（路径用 `pathlib`、加密抽象层留接口） |

编码统一 UTF-8；Windows 下终端输出需处理 GBK 回退（现有 `client.py` 已有 UTF-8 解码经验可借鉴）；路径分隔符不硬编码。

### 6.4 离线降级

- 沿用现有 `offline.py` 兜底：无网络 / 无密钥时仍可应答（规则引擎），并在 UI 明确标注"当前为离线兜底引擎，能力有限"。
- 本地文件读取、检索、（受限）命令执行**不依赖网络**，在无网环境仍可工作。
- 模型调用失败时按 `provider_chain` 自动切换并提示，全链失败后降级，不白屏、不崩溃。
- 联网检索开关在无网时自动置灰并提示原因。

### 6.5 密钥加密存储方案（分层）

| 平台 | 方案 | 说明 |
|---|---|---|
| Windows | **DPAPI**（`CryptProtectData`，`CRYPTPROTECT_LOCAL_MACHINE` 或用户态默认） | 绑定当前 Windows 账号，换账号/换机自动失效 → 提示重新填写 |
| macOS | **Keychain**（`security` 命令或 `pyobjc`） | 同上，换机失效 |
| 其他/回退 | 机器标识派生的对称加密（如 `cryptography` 的 Fernet，密钥派生自本机标识 + 随机 salt 文件） | 明确标注这是"防君子不防小人"的**混淆级**保护，不是强安全保证 |

统一抽象为 `apps/security/keystore.py` 的三个方法：`save_key / load_key / delete_key`，上层不感知平台差异。
密文文件存放于用户数据目录（`%APPDATA%\Aegis\secrets.enc`），权限收紧为仅当前用户可读写。

## 8. 交付边界（本次**明确不做**）

1. **不做**前端框架改造：不引入 React/Vue/构建工具，沿用原生 HTML/CSS/JS。
2. **不做**用户体系与多租户：桌面端单机单用户，沿用 `user_id=1`，不做登录/注册/权限。
3. **不做**代码结构大重构：不拆微服务、不改 `Aiagent/` 包名、不改 `docs/` 目录；新模块以 `apps/agent/` 形式**增量**加入。
4. **不做**向量数据库与语义 embedding 检索（P2）。
5. **不做** LSP / IDE 插件 / 编辑器集成（P2）。
6. **不做**云端同步、团队协作、多端数据互通。
7. **不做**自动更新与灰度发布（P2）。
8. **不做** Linux 安装包。
9. **不内置、不硬编码、不代申请任何 API Key**；不提供任何代理转发服务（用户密钥直连服务商）。
10. **不做**性能极致优化（如增量索引的分布式方案），达到 6.2 指标即可。
11. **不做**现有历史 `.docx` 文档的内容改写（如需同步更新另立任务）。
12. **不替用户决定**第 7 节中的任何一项，全部走确认后再进入实现。
