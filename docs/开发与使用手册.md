# Aegis 开发与使用手册

> 面向两类读者：**使用者**（怎么用 Aegis 完成日常工作）与**开发者**（怎么跑起来、怎么改、怎么排查）。
> 打包分发相关内容见 `desktop/README-打包与分发.md`，本文不重复。

---

## 1. Aegis 是什么

Aegis 是一个跑在**本机**的桌面端 AI 助手，两块能力：

| 模式 | 入口 | 能做什么 |
|---|---|---|
| 对话模式 | `/` | 普通问答、文案、翻译，可选联网检索与长期记忆 |
| 编码 Agent 模式 | `/aegis` | 在你指定的工作区内**读代码、改文件、跑命令**，多步自主迭代 |

安全模型（务必先读）：

1. 所有 `/api/*` 请求必须带本地鉴权头 `X-Aegis-Token`，只允许本机来源；
2. Agent 的文件操作被限制在**工作区目录**内，越界路径直接拒绝；
3. 写文件、改文件、执行命令**先给用户看差异/命令，等待确认**后才执行；
4. 删除、格式化、强制推送等**危险命令**不可用「本次会话允许」豁免；
5. 每次文件修改前自动备份到工作区 `.aegis_backup/<task_id>/`，支持一键回滚。

## 2. 快速上手（使用者）

### 2.1 启动

- 安装版：开始菜单 / 桌面快捷方式「Aegis」；
- 开发态：仓库根目录执行 `python main.py`，浏览器访问 `http://127.0.0.1:5000/`。

### 2.2 首次配置（向导会带你走完）

1. **选模型服务商**（智谱 / ModelScope / SiliconFlow / 通义 / Ollama 等）；
2. **填你自己的 API Key** —— 填 `<你的 API Key>`，Aegis 不内置任何密钥；
   密钥写入系统凭据管理器（Windows 凭据管理器），**不会**进配置文件；
3. **选工作区目录** —— Agent 只能读写这个目录。

### 2.3 用编码 Agent

1. 首页左侧点「Aegis 编码工作台」进入 `/aegis`（或直接访问该地址）；
2. 三栏布局：左（工作区与任务）· 中（时间线）· 右（变更清单与回滚）；
3. 在底部输入框描述任务，例如：

   - 把 `login.py` 里的登录校验抽成独立函数
   - 找出项目里所有 TODO 并汇总成清单
   - 给 `user_service.py` 补上单元测试并跑一遍

4. Aegis 会逐步：思考 → 读文件 → 提出修改（给你看 diff）→ 等你确认 → 执行 → 继续下一步；
5. 每一步的工具调用、命令输出、文件差异都在时间线里可回看（点「详情」展开）；
6. 右栏实时列出本次任务改过的文件，单条「撤销」或「全部撤销」均可回滚；
7. 「执行选项」里可开启「自动批准写入类操作」——**危险命令永远需要确认**。

### 2.4 数据都存在哪

| 内容 | 位置 |
|---|---|
| 会话与消息 | `%APPDATA%\Aegis\aegis.db` |
| 用户配置 | `%APPDATA%\Aegis\config.user.json`（不含密钥） |
| 密钥 | 系统凭据管理器 / `%APPDATA%\Aegis\secrets.enc` |
| 日志 | `%APPDATA%\Aegis\logs\aegis.log` |

## 3. 开发者指南

### 3.1 技术栈

- **后端**：Python 3.10 + Flask 3（Blueprint 分模块）
- **前端**：原生 HTML/CSS/JS（无构建工具链，Jinja2 模板 + 静态文件）
- **桌面壳**：pywebview（复用系统 WebView2）+ Werkzeug 内嵌服务
- **数据库**：SQLite（开发默认） / MySQL（可选）

### 3.2 目录结构

```
Aiagent/
├── main.py                 Flask 应用工厂 + 页面路由 + /token.js
├── requirements.txt        运行时依赖
├── apps/
│   ├── __init__.py         配置加载（原地合并 user 配置）、DB、api_ok/api_fail
│   ├── paths.py            数据目录 / 端口候选 / runtime.json
│   ├── logsetup.py         滚动日志 + 密钥脱敏
│   ├── security/           redact / errors / keystore / dpapi
│   ├── settings/           服务商与工作区设置
│   ├── llm/                多服务商接入（含 provider_caps 能力探测）
│   ├── aichat/             对话模式（会话/消息/记忆）
│   ├── websearch/          联网检索
│   ├── aicontrol/          AI 规则控制
│   └── agent/              编码 Agent 内核
│       ├── schemas.py      6 个工具的 JSON Schema
│       ├── sandbox.py      工作区路径沙箱
│       ├── approval.py     风险分级 + 人在环路审批
│       ├── fileio.py       原子写 + 备份 + unified diff
│       ├── terminal.py     子进程命令执行
│       ├── tools.py        工具实现与 dispatch
│       ├── prompts.py      系统提示词（原生 tools / JSON 回退双通道）
│       ├── parser.py       工具调用解析
│       ├── runner.py       25 步编排循环 + SSE 事件
│       ├── trace.py        变更记录与回滚
│       └── routes.py       /api/agent/*
├── desktop/                桌面壳与打包（见 desktop/README-打包与分发.md）
├── templates/  static/     页面与前端资源
├── config/config.json      默认配置（可被 config.user.json 覆盖）
└── docs/
```

### 3.3 本地开发

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

然后访问 `http://127.0.0.1:5000/`。

> Agent 相关调试：`python main.py` 起的是**多线程**服务（`threaded=True`），审批机制依赖这一点，改代码时不要退回单线程。

### 3.4 关键机制速查

**配置合并**：`config/config.json`（默认）+ `%APPDATA%\Aegis\config.user.json`（用户覆盖）→ `apps.CONFIG`。
用户配置改动后调 `apps.reload_config()`，内部用 `clear()+update()` **原地**更新，保证各模块持有的引用不失效。

**双通道工具调用**：优先用服务商原生 function calling；运行时探测到不支持（`provider_caps`）自动切 JSON 指令通道并重写系统提示词。Agent 模式**不回退**离线引擎。

**SSE 事件类型**（`/api/aichat/chat` 与 `/api/agent/run`）：
`run_start / agent_step / chunk / tool_call / terminal / tool_result / diff / file_change / approval_request / approval_resolved / notice / error / run_end / done / provider / web / blocked`。
前端约定：**未知 type 一律直接忽略**，保证旧页面零回归。

**统一错误码**：`apps/security/errors.classify()`，共 10 类（NO_PROVIDER / NO_KEY / INVALID_KEY / NO_BALANCE / NO_PERMISSION / MODEL_NOT_FOUND / RATE_LIMIT / TIMEOUT / NETWORK / SERVER_ERROR）。对外只回 `reason`（中文人话）+ `action`（下一步建议），**绝不回传原始报错**。

### 3.5 编码约定（改代码前必读）

1. 所有文件头 `# -*- coding: utf-8 -*-`；文件读写显式 `encoding="utf-8"`；
2. 路由体一律 `try/except` 包住，异常详情用 `logger.exception("中文描述")` 记日志，对外只回 `api_ok` / `api_fail`；
3. 不在日志或响应中出现密钥原文（日志经 `RedactingFilter` 脱敏）；
4. SQL 一律用占位符（`%s`），由 `apps.query/execute` 统一转 SQLite 的 `?`；
5. 前端动态内容一律 `textContent` 写入或经 `escapeText` / `escapeAttrText` 转义；
6. 密钥硬编码零容忍：占位一律写作 `<你的 API Key>`；`desktop\build.bat` 构建时会扫描并中止。

### 3.6 排查问题

1. **看日志**：`%APPDATA%\Aegis\logs\aegis.log`（密钥已脱敏）；
2. **看状态**：`GET /api/status` 返回各服务商可用性、数据库、检索配置；
3. **Agent 调试**：`GET /api/agent/tools` 返回 6 个工具的元信息；
4. **前端 401**：本地鉴权 token 失效（服务重启）→ 刷新页面重新拿 `/token.js`；
5. **页面白屏**：查模板 / 静态资源是否存在；打包态看 `_internal\templates` 是否完整。

### 3.7 测试

仓库 `tests/` 目录含既有测试。运行方式（开发机）：

```bat
python -m pytest tests -q
```

> 注意：`tests/conftest.py` 中存在**形似真实密钥的假数据**（仅用于脱敏/掩码逻辑的测试夹具）。它不进安装包，但任何密钥扫描工具都会命中它——这是预期行为，不要把它当成泄漏。

## 4. 常用入口一览

| 入口 | 说明 |
|---|---|
| `/` | 对话模式首页 |
| `/aegis` | 编码 Agent 工作台（三栏） |
| `/aichat`、`/aichat/chat` | 完整版聊天页（二级入口） |
| `/aicontrol` | AI 规则控制 |
| `/token.js` | 本地鉴权 token 下发（仅本机） |
| `/api/status` | 运行状态自检 |
| `/api/agent/run` | 启动 Agent 任务（SSE） |
| `/api/agent/approve` | 提交审批决策 |
| `/api/agent/cancel` | 取消任务 |
| `/api/agent/changes` | 查询变更清单 |
| `/api/agent/undo` | 回滚变更 |
| `/api/settings/*` | 服务商 / 工作区 / 引导信息 |
