# Aegis 1.8.2

发布日期：2026-11-16。本版承接 1.8.1，集中完善权限与任务反馈、模型选择，以及文件备份和撤销。

## 更新内容

- 完全访问模式免除工具操作审批，保留工作区路径限制；其他模式的审批规则继续生效。修复迟到的设置响应覆盖新权限选择的问题。
- 审批卡片独立显示，关闭任务详情后仍可操作。任务状态随真实事件更新，收到结束事件即可继续发送，不再等待连接收尾或侧栏刷新。
- 模型拉取结果以列表展示实际模型 ID，空清单明确报错。模型与窗口信息按服务地址和凭据绑定保存，输入框旁可切换模型；保存成功后更新当前模型与窗口。
- 实际上下文预算与输出预留遵守远端返回的窗口及输出上限；切换模型时清除上一个模型的手工窗口设置。
- 同任务多次修改同一文件时保留每次备份。可从新到旧逐条撤销，也可整体恢复任务开始前的内容。
- 撤销前校验当前文件及备份，拒绝静默覆盖后续人工修改。同文件存在较新记录时先撤销较新条目；部分失败保留失败记录，成功记录从清单移除。
- 文件恢复采用同目录临时文件和原子替换，重新校验工作区路径，避免恢复失败留下半截文件。
- 安装器每次显示目录选择页，支持自行命名文件夹，不再自动追加 Aegis 子目录。

## 安装与升级

安装包：`Aegis-Setup-1.8.2.exe`；校验文件：`Aegis-Setup-1.8.2.sha256`。

安装前退出旧版。安装器沿用固定应用标识，覆盖升级保留用户配置、会话、密钥与技能；用户数据继续保存在 `%APPDATA%\Aegis`。需要 64 位 Windows 10 1809 或更高版本及 Microsoft Edge WebView2。

安装包未签名，Windows 可能提示未知发布者。请从本项目的 [GitHub Releases](https://github.com/Qiu1717/Aegis-demo/releases) 下载，并核对 SHA-256。

## 验证与限制

- 完整后端测试：405 passed、4 skipped；跳过项因当前 Windows 账号无符号链接创建权限。
- 全部前端回归：11 个测试文件，50 项通过。
- 产物检查包含敏感文件扫描、静态资源比对，以及隔离数据目录、独立端口下的页面、关键接口和桌面窗口关闭验证。
- 旧记录没有可信的写后状态和完整逐次备份，安全拒绝自动撤销，需人工核对备份后恢复。撤销没有跨进程文件锁或事务隔离，不应在其他程序同时写入时执行。
- 未使用用户真实密钥进行收费模型效果、速度或成功率评测。文件工具的工作区路径限制不是操作系统级隔离。
