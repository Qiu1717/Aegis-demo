# Aegis 1.8.1

本次从 1.8.0 升级到 1.8.1，重点完善桌面工作台、模型配置、技能扩展与多轮任务执行。此前未发布的本地测试改动合并在本版中。

## 新增功能

### 外部技能导入

- 在技能中心导入本地 JSON、SKILL.md 或 ZIP 技能包。
- 通过公开 GitHub 仓库、目录或文件链接拉取技能，保存到本地。
- 导入后手动启用，完整技能指令进入 Agent 上下文；包内参考文档可由专用只读工具读取。
- 外部技能脚本不会在导入时自动执行。

### 文件附件与工作区选择

- 输入框支持添加 UTF-8 文本和代码文件，附件内容进入实际模型请求。
- 工作区选择移至输入框左下，便于在提问时确认当前项目。
- 每个附件最多 2 MiB，每轮最多 8 个、合计 8 MiB。

### 只读计划模式与仓库约定

- 新增只读计划模式，允许读取和检索，服务端拒绝写文件、编辑和命令执行。
- 自动加载工作区根目录的 `AGENTS.md`、`CLAUDE.md` 与 `.aegis/instructions.md`；存在 `AGENTS.override.md` 时优先于 `AGENTS.md`。
- 显示规划、执行、验证和整理结果等阶段，帮助查看任务进度。

### 外观设置

- 采用暖灰、纸白、炭黑的桌面工作台设计，支持浅色、深色和跟随系统。
- 可保存对话字号、侧栏默认折叠和任务详情展开偏好。
- 优化设置弹窗、审批卡片、窄屏和小窗口布局。

## 优化与修复

### 模型配置更直接

- 移除故障切换链，调用只使用选中的预设或自定义模型，不自动切换到其他服务商。
- 修复模型列表拉取的前端误报、地址拼接和已保存密钥复用问题。
- 区分鉴权、网络、超时、限流与模型列表接口不支持等错误，便于定位原因。
- 温度、超时、输出上限和上下文窗口预算接入实际请求。

### 多轮对话更稳定

- 修复点击停止后立即发送新消息时，旧请求回调误停新任务的问题。
- 迟到的暂停事件、错误及收尾不再覆盖新一轮状态。
- 会话 ID 在任务开始时回传，停止后继续提问能沿用同一会话。
- 修复历史消息响应乱序，以及切换、删除会话时附件残留或串入其他会话的问题。

### 工具调用与上下文处理更可靠

- 一次返回多个原生工具调用时，保留完整调用组及对应结果，避免配对错误。
- 命令退出码非零、超时和取消会正确反馈给 Agent，避免把失败误判成成功。
- 对长任务应用上下文预算、按工具组裁剪和超大结果压缩，保留消息协议与合法 JSON。
- 修复暂停中的任务取消后无法及时退出或额外调用模型的问题。

### 界面反馈更及时

- 默认会话标题在任务开始时更新，保留手动重命名。
- 侧栏可见时每 5 秒同步，切回窗口立即刷新；数据不变时不重建列表。
- 移除输入框联网搜索开关，默认启用搜索，由 Agent 按任务与权限决定是否调用。
- 移除侧栏底部模型名称，模型配置仍保留在设置中。

## 与 1.8.0 对比

| 方面 | 1.8.0 | 1.8.1 |
|---|---|---|
| 模型使用 | 故障切换链 | 选中单模型，失败明确反馈 |
| 技能扩展 | 工作台缺少外部导入入口 | 本地导入与公开 GitHub 拉取 |
| 提问资料 | 主要输入文字 | 支持文本/代码附件 |
| 计划与规范 | 通用任务流程 | 只读计划模式、仓库规则、阶段反馈 |
| 停止后继续 | 旧请求可能影响新任务 | 每轮请求状态隔离 |
| 会话标题 | 更新滞后 | 开始时更新，保留自定义名称 |
| 桌面外观 | 原有布局与配色 | 中性色布局，可保存外观偏好 |

## 安装与升级

安装包：`Aegis-Setup-1.8.1.exe`，SHA-256 校验文件：`Aegis-Setup-1.8.1.sha256`。

需要 64 位 Windows 10 1809 及以上和 WebView2。先完全退出旧版，再运行安装程序；沿用原应用标识，覆盖升级时保留会话、配置、密钥和技能。安装包未签名。

## 验证与当前限制

- 后端全量回归：379 passed、3 skipped；全部 10 个 JavaScript 测试文件通过。
- 打包资源与源码一致，隔离数据和独立端口下的桌面启动、关闭及关键接口检查通过。
- 安装包不包含本地用户数据库、配置或密钥。
- 上下文窗口设置参与本地请求预算，不能将模型扩展到服务商不支持的窗口大小；token 当前为估算。
- 附件暂不支持 PDF、Word 解析或图片识别；GitHub 技能暂不支持私有仓库。
- 默认搜索不等于每条消息都搜索，纯对话权限下不执行工具。
- 本版没有新增模型速度或动画优化，也未通过真实收费模型 A/B 测试量化速度、质量或成功率提升。

## 发布前复测建议

1. 从 1.8.0 升级，确认模型配置与会话保留。
2. 发送问题、停止后立即再次发送，确认新回答不会被旧任务中断。
3. 检查自动标题更新，手动重命名后确认不会被覆盖。
4. 验证模型拉取、文本附件、技能导入与启用、只读计划模式和外观保存。
