欢迎使用 Aegis 桌面版

第 1 / 3 步

Aegis 是能读你本地代码、改文件、跑命令的编码助手。

  • 本应用不内置任何 API Key，需要你填入自己的密钥
  • 密钥将加密保存在本机，不会上传
  • 配置 API Key 后即可使用大模型服务，未配置时仅能应答简单问题

选择一个模型服务商（智谱 GLM 的 GLM-4-Flash 永久免费，推荐）

    弹出系统目录选择器，可浏览各磁盘分区；Aegis 只会读写这个目录内的文件

    🔒 密钥加密保存在本机（Windows 凭据管理器 / DPAPI，绑定当前账号）
